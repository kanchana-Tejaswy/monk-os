<h2>1. Introduction</h2>

<p>
<b>monk mode</b> is not a traditional productivity application, habit tracker, or task manager.
It is a <b>Self-Mastery Operating System</b> designed to help individuals align action, discipline,
focus, and purpose into a single integrated digital environment.
</p>

<p>
Modern productivity tools optimize for speed and output. They encourage users to complete more tasks,
switch contexts rapidly, and chase artificial streaks. While effective temporarily,
these systems often lead to burnout, distraction, and identity fragmentation.
</p>

<p>
monk mode challenges that paradigm.
</p>

<p>
Instead of optimizing for activity, monk mode optimizes for <b>clarity, integrity,
and identity transformation</b>.
</p>

<p>
The application treats life as a system that can be intentionally designed,
measured, and evolved.
</p>

<h2>2. Core Philosophy</h2>

<h3>2.1 Peace Over Productivity</h3>

<p>
Most productivity applications operate on urgency and pressure.
monk mode operates on stillness and awareness.

<blockquote>

<h3>2.3 The 48-Hour Integrity Rule</h3>

<p>
The defining principle of monk mode is radical honesty.
</p>

<p>
Most habit trackers allow users to edit history and preserve streaks.
This creates a psychological illusion of discipline.
</p>

<p>
monk mode removes this illusion entirely.
</p>

<ul>
<li>Actions must be logged within <b>48 hours</b>.</li>
<li>After 48 hours, entries permanently lock.</li>
<li>No backfilling. No rewriting history.</li>
</ul>

<p>
The system motto:
</p>

<blockquote>
Hard Data. Zero Lies.
</blockquote>

<p>
The objective is not perfection — it is truthful awareness.
</p>

<h2>4. Technical Architecture</h2>

<h3>4.1 Frontend Framework</h3>

<ul>
<li><b>Next.js 15 (App Router)</b> — Modern React architecture using server components for optimal performance.</li>
<li><b>React 19</b> — Enables concurrent rendering and responsive UI updates.</li>
<li><b>TypeScript</b> — Ensures strict type safety across the entire application.</li>
</ul>

<p>
Server Components handle data orchestration,
while Client Components power interaction-heavy dashboards.
</p>

---

<h3>4.2 Design System & UI Layer</h3>

<ul>
<li><b>Tailwind CSS v4</b> — Utility-first styling system.</li>
<li><b>Custom Theme Tokens</b> — Establish visual identity consistency.</li>
<li><b>Framer Motion</b> — Animation engine delivering premium tactile interactions.</li>
<li><b>Lucide React</b> — Minimal iconography aligned with calm aesthetics.</li>
<li><b>next-themes</b> — Seamless Light/Dark mode switching.</li>
</ul>

<p>
Animations are intentional, never distracting.
Motion communicates meaning rather than decoration.
</p>

---

<h3>4.3 Backend & Data Persistence</h3>

<ul>
<li><b>Supabase</b> — PostgreSQL database and authentication layer.</li>
<li>Row Level Security (RLS) prepared for multi-tenant scaling.</li>
<li>Hybrid persistence architecture.</li>
</ul>

<h4>Guest Mode Engine</h4>

<p>
The application currently operates in ultra-fast Guest Mode:
</p>

<ul>
<li>localStorage persistence</li>
<li>Instant load times</li>
<li>Offline capability</li>
<li>Structured JSON state management</li>
</ul>

<p>
Users experience zero network latency while maintaining future cloud readiness.
</p>

---

<h3>4.4 Progressive Web Application</h3>

<p>

<ul>
